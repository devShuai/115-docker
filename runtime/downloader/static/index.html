        安装客户端 · agent 非交互调用

        Python 3.8+ 标准库客户端，无需 pip 或 Docker。凭据从环境或密码文件读取；全局参数放在子命令前。

        凭据优先级：--password → --password-file / DOWNLOAD_API_PASSWORD_FILE → DOWNLOAD_API_PASSWORD → API_PASSWORD。地址使用 --url / DOWNLOAD_API_URL，用户名使用 --user / DOWNLOAD_API_USER。

        --no-input 禁止询问密码；--json 成功输出到 stdout，失败输出 {error,status} 到 stderr。退出码：成功 0，失败 2；本地输入或连接错误 status 为 null。

        调用约定与错误

        错误响应统一为 {"error":"说明"}。云下载使用 percent 0–100，NAS 传输使用 progress 0–1；以 state=done 确认完成。提交下载后的 200 表示任务已提交。POST 超时后先查询已有任务，避免重复提交。
